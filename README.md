SEVENTEEN · 缝纫设备智能流转系统

SEVENTEEN Sewing Equipment Intelligent Flow Management System
专为服装制造工厂、生产车间与缝纫设备门店打造的数字化设备库管与全生命周期追踪平台。
 核心优势：本系统接入 Supabase 云端实时数据库，支持电脑、平板、手机及门店大屏多端秒级同步；内置 RBAC 四级权限管控、单机二维码溯源、电子手写签名与智能图片压缩引擎。
 六大高频业务场景实操指南

1. 日常入库与多机批量录码
登录后在设备看板选择「入库」，填写设备名称、型号与数量。若一次购入多台同款设备，可在序列号 (SN) 栏用英文逗号 , 分隔（如 SN01,SN02,SN03），系统会自动建立独立单机台账并支持历史下拉联想。
2. 车间借调、超期预警与分批归还
外借给合作工厂或车间时选择「借出」并点击快捷标签（+3天/+7天/+30天）设定预计归还日；超期未还将在顶部红框预警并支持一键复制微信催还话术。归还时可勾选具体归还的 SN 码，支持分批部分归还。
3. 单机生命周期与扫码溯源
点击表格中任意序列号 (SN) 蓝色标签或设备名称，即可查看该台设备的完整流转时间线，并可一键打印专属二维码贴纸贴于机身；现场通过顶部「扫一扫查设备」或手机相机扫码即可直达档案。
4. 现场拍照留证与电子手写签名
登记流转时支持多图拍摄机身成色、铭牌或单据（自动压缩不占空间），也可点击「电子手写签名」让领用人直接在手机/平板屏幕上签字确认，签名将自动嵌入打印交接单。
5. 实时库存台账与车间分布统计
点击顶部「库存台账」可按设备品类汇总或车间/产线分布实时查看在库可用数、借出占用数与维修中数量；在「缝纫统计」中可查看近 30 天流转趋势图与各机型汇总。
6. 标准交接单打印与数据容灾备份
每条记录右侧「操作 → 交接单」可一键打印带厂名抬头的标准交接凭证单；支持导出 Excel / PDF 报表，建议定期在「云端与数据」导出 .json 备份文件留存。
